    85→    85→# PART 2 — PRODUCT VISION
    86→    86→
    87→    87→WALLORA is not simply a wallpaper application.
    88→    88→
    89→    89→It is an AI-powered creative platform where users can discover visual content, communicate with AI, generate artwork, edit images, build projects, interact with creators, publish digital creations and monetize their work.
    90→    90→
    91→    91→The product should combine the best ideas behind:
    92→    92→
    93→    93→- Pinterest: visual discovery and inspiration.
    94→    94→- ChatGPT: conversational AI assistance.
    95→    95→- Canva: accessible creative tools.
    96→    96→- Instagram: profiles and community.
    97→    97→- Creative marketplaces: digital products and creator monetization.
    98→    98→- AI image studios: image generation and editing.
    99→    99→- Personalization applications: wallpapers, collections and digital aesthetics.
   100→   100→
   101→   101→These are product references, not instructions to copy their branding, interfaces or proprietary designs.
   102→   102→
   103→   103→## Core product promise
   104→   104→
   105→   105→A user should be able to enter WALLORA with an idea and leave with something they have created, discovered, organized, shared or purchased.
   106→   106→
   107→   107→Example:
   108→   108→
   109→   109→A user opens WALLORA and types:
   110→   110→
   111→   111→"I want to create a futuristic luxury bedroom design with black walls, golden lighting, a gaming setup and a large window overlooking Nairobi."
   112→   112→
   113→   113→WALLORA AI should understand the request, help refine it, select a suitable creative tool, generate a visual concept using an available model, display the result, and allow the user to save it inside a project.
   114→   114→
   115→   115→Another user might ask:
   116→   116→
   117→   117→"Give me five wallpapers that match my dark minimalist phone setup."
   118→   118→
   119→   119→WALLORA should understand the request and search the approved wallpaper library.

  1381→  1381→5. Generate short-lived signed upload URL.
  1382→  1382→6. Upload directly to R2.
  1383→  1383→7. Verify uploaded object.
  1384→  1384→8. Send job to worker.
  1385→  1385→9. Process image using Sharp.
  1386→  1386→10. Extract image dimensions.
  1387→  1387→11. Remove sensitive EXIF metadata where appropriate.
  1388→  1388→12. Generate image variants.
  1389→  1389→13. Run moderation.
  1390→  1390→14. Save asset metadata.
  1391→  1391→15. Publish only after approval.
